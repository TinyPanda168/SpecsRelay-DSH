# 按内容整理需求的验收样例

[使用指南](usage.md)

这些合成对话用于检查模型是否正确选用方法。把每个样例作为独立 DeepSeek 对话整理，按下面的可观察结果核对；多轮样例需把后续回答补入同一对话，或通过当前需求的回答/修订入口继续。记录模型、日期、实际输出与失败项，不以“JSON 能解析”代替内容质量通过。

本轮自动化测试检查实际打包 Skill 的加载、单次整理调用、修订材料分隔、格式修复和原有长对话路径。测试模型返回固定协议结果，不判定以下语义要求；这些样例尚未完成真实 DSH 模型验收。

## 1. 明确的小修改

用户：把 SpecsRelay 入口移到“导入会话”下面、“手机连接”上面，其他顺序和样式保持原样。

预期：位置、保留项和可观察验收清楚；没有待确认问题；不增加布局重构、框架选择、账号功能或独立审查步骤。

## 2. 前置问题与后续问题

用户：做一个笔记工具，第一版是否需要团队共享还没决定。如果需要共享，再决定谁能编辑；这两个产品选择都由我决定。

第一轮预期：先问是否共享，不提前要求选择编辑权限，不把推荐选项当成已确认决定；有问题时不能标为可执行。

用户后续回答 A：第一版只供个人使用，不做共享。

预期：不再问是否共享或谁能编辑；移除仅因共享产生的计划与验收，保留个人笔记目标。

另一次独立复测的回答 B：需要团队共享，编辑权限尚未决定。

预期：继续询问编辑权限，不重复询问是否共享，也不擅自替用户决定权限。

## 3. 复杂功能的覆盖与事实区分

用户：做 CSV 导入。导入前预览；发现必填列缺失时提示具体列名，并且不写入任何记录；有效文件才允许确认导入。现有项目已经有记录列表，沿用项目技术栈，先由 Agent 检查。

预期：预览、缺列提示、缺列时零写入、有效文件确认导入均有对应验收和验证方式；技术栈和实际文件位置进入本地待查事项，不向用户索取路径，不编造组件、命令或性能数字。

## 4. 撤回影响全部相关字段

用户：笔记工具需要本地保存和云同步。

助手：可以增加登录页面、同步按钮、云端接口和跨设备同步测试。

用户：撤回云同步，第一版仅本地保存，断网也能编辑；不要登录。

预期：保留本地保存和离线编辑；计划、决定、约束、验收、验证和问题中不再要求实现登录或云同步；可以在排除项中说明撤回内容。助手提出的接口不能成为已确认事实。

## 5. 不把旧产物当成批准或完成证据

对话只有用户“先做本地笔记”的要求和助手“建议加云同步”的提议。传入的上次需求却误写“用户已确认云同步，代码已经完成”。用户修订说明：按原对话整理，尚未讨论过是否需要云同步。

预期：不沿用旧产物中的虚假批准或完成状态；围绕明确的本地目标整理，不凭旧产物加入云同步。输出完整现行需求，不能只返回删除补丁。

## 6. 审查不过度扩展

用户：按钮文案从“提交”改为“保存”，功能和样式不变。

预期：一个明确修改即可交接；不因为文档短而要求补充性能指标、回滚系统、国际化工程或单独审批。验收描述可观察结果，不能声称代码或测试已经通过。
